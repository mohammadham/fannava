# قالب فناوا - نسخه فارسی RTL

## راهنمای نصب و استفاده

این قالب به طور کامل برای زبان فارسی و جهت راست به چپ (RTL) بهینه‌سازی شده است.

---

## تغییرات اعمال شده

### 1. فونت فارسی
- فونت **شبنم** به قالب اضافه شد
- فایل‌های فونت در مسیر `/assets/fonts/` قرار دارند
- فونت شامل وزن‌های مختلف: عادی، ضخیم، نازک، سبک و متوسط

### 2. پشتیبانی RTL
- فایل `style-rtl.css` در ریشه قالب ایجاد شد
- فایل `fannava-rtl.css` در مسیر `/assets/css/` با تمام استایل‌های RTL
- تگ HTML با ویژگی‌های `dir="rtl"` و `lang="fa"` به‌روزرسانی شد

### 3. ترجمه فارسی
- فایل‌های ترجمه `fa_IR.po` و `fa_IR.mo` در پوشه `/languages/` ایجاد شدند
- تمام متن‌های قالب به فارسی ترجمه شدند:
  - منوها
  - فرم‌ها
  - دکمه‌ها
  - پیام‌های سیستمی
  - نظرات

### 4. فایل‌های تغییر یافته
```
/header.php              - اضافه شدن RTL و lang="fa"
/functions.php           - ترجمه متن‌های هارد‌کد
/inc/common/fannava-scripts.php  - اضافه شدن فونت شبنم و CSS های RTL
/assets/css/shabnam-font.css     - فایل فونت شبنم (جدید)
/assets/css/fannava-rtl.css      - استایل‌های RTL (جدید)
/style-rtl.css           - فایل اصلی RTL قالب (جدید)
/languages/fa_IR.po      - فایل ترجمه فارسی (جدید)
/languages/fa_IR.mo      - فایل ترجمه کامپایل شده (جدید)
```

## نحوه استفاده

### 1. آپلود قالب
- فایل‌های قالب را در مسیر `/wp-content/themes/fannava/` آپلود کنید
- از طریق پنل وردپرس به **ظاهر > پوسته‌ها** بروید
- قالب Fannava را فعال کنید

### 2. تنظیمات زبان
برای فعال‌سازی کامل زبان فارسی:

1. به **تنظیمات > عمومی** بروید
2. زبان سایت را روی **فارسی** تنظیم کنید
3. تغییرات را ذخیره کنید

### 3. بررسی RTL
- قالب به صورت خودکار در حالت RTL اجرا می‌شود
- تمام محتوا از راست به چپ نمایش داده می‌شود
- فونت شبنم به صورت پیش‌فرض اعمال شده است

### 4. فایل تست
یک فایل تست HTML در مسیر `/rtl-test.html` قرار دارد که می‌توانید با باز کردن آن در مرورگر، نتیجه تغییرات RTL را مشاهده کنید:
```
https://your-domain.com/wp-content/themes/fannava/rtl-test.html
```

## عیب‌یابی

### مشکل: فونت فارسی نمایش داده نمی‌شود
**راه حل:**
1. کش مرورگر را پاک کنید
2. اگر از افزونه کش استفاده می‌کنید، کش آن را پاک کنید
3. بررسی کنید فایل‌های فونت در مسیر `/assets/fonts/` وجود دارند

### مشکل: محتوا راست‌چین نیست
**راه حل:**
1. بررسی کنید فایل `style-rtl.css` بارگذاری شده است
2. کش را پاک کنید
3. در کد منبع صفحه، بررسی کنید که `<html dir="rtl">` وجود دارد

### مشکل: ترجمه‌ها نمایش داده نمی‌شوند
**راه حل:**
1. زبان سایت را در **تنظیمات > عمومی** روی فارسی تنظیم کنید
2. بررسی کنید فایل‌های `fa_IR.po` و `fa_IR.mo` در پوشه `/languages/` هستند
3. افزونه‌های کش را غیرفعال و دوباره فعال کنید
